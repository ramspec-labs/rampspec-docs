RampSpec documentation is exported as a static Mintlify site and is configured for public Vercel hosting without embedding runtime credentials.

## Build contract

`npm run build` validates TypeScript, content, navigation, links, generated references, examples, spelling, and formatting. It then creates `export.zip`, rejects unsafe archive paths, replaces `out/`, confirms `out/index.html`, and removes the ZIP.

Vercel uses the same command and publishes only `out/`.

## Public indexing

The repository and documentation channel are public. Mintlify is configured as public, `robots.txt` permits crawling, and Vercel does not add a no-index response header. Preview deployments may still use account-level access controls when they contain unreleased content.

## Search and canonical URLs

Mintlify generates `sitemap.xml`, `robots.txt`, and canonical tags during hosted builds. Canonical URLs follow the final deployment domain; no unverified RampSpec domain is hard-coded. In-product search uses page keywords and navigation boosts. Search analytics are reviewed in the Mintlify dashboard and must not be joined to RampSpec account, target, report, or identity data.

## Deployment evidence

A successful local export proves buildability, not public availability. The release record must name the source commit and hosted URL, and a maintainer must verify the home page plus the reviewer quickstart after deployment.
