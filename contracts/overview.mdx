RampSpec contracts are planned Soroban interfaces for compact evidence commitments and controlled authentication fixtures. Production evidence contracts and test fixtures are separate classifications and must be labeled in every generated reference and deployment record.

## Status

No contract specification, WASM hash, network address, or deployment manifest is released yet. Contract pages are generated from tagged artifacts rather than copied from implementation prose.

The [contract storage reference](/reference/contract-storage) defines the import, verification, privacy, and deployment boundary until the contracts repository publishes its first compatible release. The [release manifest](/reference/release-manifest) will bind that artifact to compatible backend and docs versions.
