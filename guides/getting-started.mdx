The guided setup path will take a contributor from a clean checkout to a verified synthetic test run.

## Planned sequence

1. Pin compatible repository tags from the release manifest.
2. Install locked dependencies and run focused checks.
3. Configure a synthetic, authorized testnet target.
4. Lock a rule and scenario suite.
5. Run a non-destructive discovery check and verify its report.

The exact commands are intentionally withheld until the backend publishes the API, CLI, schema, and report artifacts they must target.
