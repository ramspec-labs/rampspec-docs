description: "Choose the implemented reviewer workflow or a deeper repository-specific path."
---

Use the [reviewer quickstart](/guides/reviewer-quickstart) for the shortest executable path through the backend and frontend.

For repository work, install each pinned toolchain and run its complete verification command before changing behavior:

- backend: `pnpm check`;
- frontend: `pnpm verify` and `pnpm build`;
- contracts: `cargo test --locked --workspace` plus the Node script tests;
- docs: `npm test` and `npm run build`.

Generated OpenAPI and contract artifacts remain owned by their source repositories. Documentation imports them with commit and digest provenance rather than redefining them.
