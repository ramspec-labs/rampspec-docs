title: "SDK overview"
description: "The entry point for RampSpec client, verifier, runner, schema, webhook, and contract packages."
---

The RampSpec SDK surface is planned as a set of narrow packages for API clients, report verification, runner integration, schema helpers, webhook signatures, and read-only contract lookups.

## Availability

No package release is published yet. Install commands will be added only after the backend or contracts repository publishes a compatible package and the command is checked in a clean environment.
