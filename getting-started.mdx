RampSpec now includes a narrow, implemented reviewer path: the backend probes an explicitly approved HTTPS target, records the result in a durable local store, and returns a report that the frontend renders without recalculating it.

## Fastest path

1. Follow the [reviewer quickstart](/guides/reviewer-quickstart) to start the backend and submit one reference run.
2. Open the frontend reviewer form and confirm that the same backend report is displayed.
3. Inspect the generated [API reference](/api-reference/endpoints) and the repository test commands.
4. Use only authorized synthetic or public test targets. The workflow is evidence of the implemented reference slice, not certification of a target.

## Current boundary

The reference slice covers SEP-1 reachability and advertised support. Broader protocol suites, hosted runners, production authentication, and pubnet publication remain outside this reviewer path unless a later release manifest names them.
