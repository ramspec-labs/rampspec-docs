Getting started is the controlled entry path for a new RampSpec contributor or integration owner.

## Current status

The four runtime repositories currently contain implementation plans and no tagged API, schema, contract, CLI, or deployment release. This page therefore explains the documented path without presenting commands that cannot be verified against a release.

## Reading order

1. Read the [introduction](/introduction) and [architecture overview](/architecture/overview).
2. Confirm the [four-repository ownership model](/governance/repository-ownership).
3. Use the [guided setup path](/guides/getting-started) when a tagged runtime release exists.
4. Check the [roadmap](/roadmap) and release manifest before treating a result as evidence.

## Safety boundary

Use synthetic identity data and authorized testnet targets. Do not submit real customer information, production credentials, or unrestricted pubnet transactions while following an unreleased guide.
